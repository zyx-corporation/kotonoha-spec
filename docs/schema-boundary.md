# Schema boundary note

Status: Informative design note.

This note records that detailed machine-readable schema work is future work and does not change Phase 1 conformance.

Phase 1 keeps only the minimal logical shapes defined in SLS-3, SLS-4, SLS-5, SLS-7, and SLS-8.

Future work may cover lineage records, RDE review items, reviewability metadata, source-context status, audit references, and version envelopes.

Future schema artifacts should say whether they are normative, informative, or implementation-specific. They should cite the relevant SLS section identifiers and follow SLS-8 for version changes.
